KAYCEE B. MANALO — VA PORTFOLIO

HOW TO OPEN
1. Extract this ZIP folder.
2. Double-click index.html to preview it in your browser.
3. For best results during development, open the folder in VS Code and use Live Server.

TECH
- HTML5
- Tailwind CSS via CDN
- Vanilla JavaScript

IMPORTANT
- The portfolio gallery uses only the works that were present in the supplied assets collection.
- Tailwind CSS is loaded from the official CDN, so an internet connection is needed for styling when previewing the raw HTML locally.
- All supplied images, resume, spreadsheet, and video are included in the assets folder.
